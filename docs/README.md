# Documentação do projeto

Esta pasta reúne as **notas de entrega** e as **validações de QA** geradas a cada
funcionalidade. Nenhum destes arquivos é necessário para o sistema rodar — servem
como histórico e rastreabilidade. O `README.md` principal fica na raiz do projeto.

## Notas de entrega (o que cada pacote adicionou)
- `README_INTEGRACAO_SUBCOMPONENTES.md` — integração da área **Subcomponentes** no menu.
- `README_FLUXO_LIBERACAO_AUTOMATICO.md` — fluxo de liberação automático de séries de lotes.
- `README_PAINEL_SERIES_FLUXO_LOTES.md` — painel de séries (fluxo horizontal) em `ensaios.html`.
- `README_REFRESH_RUMO.md` — aplicação do visual da marca Rumo.
- `README_ZOOM_OUT_RUMO.md` — ajuste global de densidade / zoom.

## Validações (QA de cada entrega)
- `VALIDACAO_BRANDBOOK_RUMO.md` — identidade visual Rumo.
- `VALIDACAO_BRAND_ASSETS_RUMO_V2.md` — brand assets (v2).
- `VALIDACAO_TECNICA_RUMO.txt` — checagem de resíduos de marca antiga.
- `VALIDACAO_PERMISSOES.md` — permissões Admin / Fiscalização / Consulta.
- `VALIDACAO_USUARIOS_UI.md` — tela de Usuários.
- `VALIDACAO_AUDITORIA_UI.md` — aba Auditoria.
- `VALIDACAO_GLOSSARIO_SUBCOMPONENTES.md` — glossário de subcomponentes (2 abas).
